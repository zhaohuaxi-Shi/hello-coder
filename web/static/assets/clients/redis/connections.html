基本信息
Standalone 连接

填写 Redis 数据节点地址（通常 6379），不要填 Sentinel / 集群代理端口。

Cluster 连接

填写集群 Seed 节点，逗号分隔。DB 固定为 0（与 ARDM Cluster 一致）。

Sentinel 连接

填写 Sentinel 地址（常见 26379）和 Master name，不要只填数据节点地址。
