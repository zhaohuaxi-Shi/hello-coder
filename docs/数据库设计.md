# Hello Coder 数据库设计文档

> 存储引擎：SQLite（单文件）  
> 库文件路径：`{HELLO_CODER_DATA_DIR}/hello-coder.db`（默认 `./data/hello-coder.db`）  
> ORM：GORM AutoMigrate（进程启动时检查库文件，不存在则创建，并同步表结构）

---

## 1. 总览

| 项 | 说明 |
| --- | --- |
| 数据库类型 | SQLite |
| 驱动 | `github.com/glebarez/sqlite`（纯 Go / modernc，无 CGO） |
| 主键策略 | 整型自增（`INTEGER PRIMARY KEY` / GORM `uint`） |
| 时间字段 | `created_at` / `updated_at`（GORM 自动维护） |
| 密码策略 | 登录密码存 bcrypt；连接密码传输 RSA-OAEP、落库 AES-GCM（`hc1:` 前缀） |
| 多工具扩展 | 主表 `user`；各工具独立连接表（如 `kafka_conn`、`es_conn`、`redis_conn`） |

### 1.1 ER 关系（当前）

```text
┌────────────┐         1:N          ┌──────────────┐
│    user    │─────────────────────▶│  kafka_conn  │
│            │      user_id         │  （创建人）    │
│            │─────────────────────▶│   es_conn    │
│            │      user_id         │  （创建人）    │
│            │─────────────────────▶│  redis_conn  │
│            │      user_id         │  （创建人）    │
└────────────┘                      └──────────────┘
```

说明：`*_conn.user_id` 表示**创建人**（当前仅支持本人创建、本人使用）。未在 SQLite 层强制外键，由应用层校验。

## 2. 表结构

### 2.1 `user`（用户主表）

对应模型：`internal/model/user.go`

| 字段 | 类型（逻辑） | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | INTEGER | PK，自增 | 用户主键 |
| `username` | VARCHAR(64) | NOT NULL，UNIQUE | 登录名；建议 3–32，字母/数字/下划线 |
| `password` | VARCHAR(255) | NOT NULL | bcrypt 哈希，接口层不回传 |
| `created_at` | DATETIME | — | 注册时间 |
| `updated_at` | DATETIME | — | 最近更新时间 |

**索引**

| 名称 / 类型 | 字段 | 说明 |
| --- | --- | --- |
| PRIMARY | `id` | 主键 |
| UNIQUE | `username` | 登录唯一 |

---

对应模型：`internal/model/kafka_conn.go`

| 字段 | 类型（逻辑） | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | INTEGER | PK，自增 | 连接主键 |

| `sasl_username` | VARCHAR(128) | 可空 | SASL 用户名 |
| `sasl_password` | VARCHAR(512) | 可空 | SASL 密码（AES-GCM 密文，列表不回传） |
| `description` | VARCHAR(512) | 可空 | 备注 |
| `created_at` | DATETIME | — | 创建时间 |
| `updated_at` | DATETIME | — | 最近更新时间 |

**索引**

| 名称 / 类型 | 字段 | 说明 |
| --- | --- | --- |
| PRIMARY | `id` | 主键 |
| INDEX | `user_id` | 按创建人查询连接列表 |

## 3. 生命周期

| 阶段 | 行为 |
| --- | --- |
| 启动 | 检查 `{dataDir}/hello-coder.db`；不存在则新建 |
| 迁移 | `AutoMigrate(User, KafkaConn, EsConn, RedisConn)`；若存在旧列 `created_by` 则删除 |
| 备份 | 拷贝 `hello-coder.db`（建议停写或使用 backup API） |

实现位置：`internal/store/db.go`。

---

## 4. 安全约定

1. `user.password`、`kafka_conn.sasl_password`、`es_conn.password`、`redis_conn.password` 不得出现在普通列表/日志中。
2. 连接密码：浏览器用 RSA-OAEP（公钥 `GET /api/v1/crypto/public-key`）加密后提交；服务端解密后以 AES-GCM 写入 SQLite（值前缀 `hc1:`）。历史明文记录读取时仍兼容，保存后升级为密文。
3. 生产环境修改 `HELLO_CODER_JWT_SECRET` 与 `HELLO_CODER_DATA_KEY`；限制库文件与 `data/transport_rsa.pem` 本机权限。
